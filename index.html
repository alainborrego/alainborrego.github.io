Projects

Temperature-Controlled Cooling System

Designed and programmed an automated temperature-control system using an NTC thermistor, Arduino, 16x2 LCD, L293D motor driver, and DC fan. The system monitors temperature in real time and automatically controls the fan using hysteresis-based temperature thresholds.

Technologies: Arduino, C++, Sensors, Electronics, L293D, LCD

OrthoSense Fall Detection Cane Attachment

Designed and prototyped a clip-on assistive device for detecting falls in cane users. Led CAD modeling and mechanical design of the housing while contributing to integration of an Arduino-based tilt sensor, LED, and buzzer alert system.

Technologies: Onshape, Arduino, CAD, Prototyping, Sensors

Bulls and Cows Analytics Suite

Developed a Python-based analytics system for evaluating gameplay data from Bulls and Cows. The program processes player performance data, calculates statistics, analyzes win rates across difficulty levels, generates visualizations, and produces automated reports.

Technologies: Python, Data Analysis, Data Visualization, CSV Processing
