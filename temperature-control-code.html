Code & Implementation

Temperature-Controlled Cooling System

The program is divided into several tasks: defining the hardware, reading the thermistor, converting the sensor reading into temperature, controlling the fan using hysteresis, and updating the LCD with real-time system information.

← Back to Project

1. Hardware & System Configuration

The first section defines the electrical characteristics of the thermistor circuit, the Arduino pins being used, the fan temperature thresholds, and the LCD connections. 

#include <LiquidCrystal.h>

// ---------- Thermistor ----------

const float referenceVoltage = 5.0;
const int maxADC = 1023;
const float fixedResistance = 5100.0;
const float nominalResistance = 10000.0;
const float nominalTemperature = 25.0;
const float beta = 3950.0;

// ---------- Pins ----------

const int thermistorPin = A0;
const int fanPin = 9;

// ---------- Fan Control ----------

bool fanOn = false;

const float fanOnThreshold = 28.0;
const float fanOffThreshold = 27.0;

// ---------- LCD ----------

LiquidCrystal lcd(12, 11, 5, 4, 3, 2);

Using named constants makes the program easier to read and allows hardware values such as resistor resistance, pin assignments, and temperature thresholds to be changed from one location.

2. Temperature Conversion Function

The Arduino cannot directly measure the resistance of the thermistor. Instead, it measures the voltage produced by the thermistor voltage divider. This function converts that analog reading into temperature in degrees Celsius. 

float convertToTemperature(int rawReading)
{
    float voltage;
    float resistance;
    float temperature;

    voltage = (rawReading * referenceVoltage) / maxADC;

    resistance =
        fixedResistance * (referenceVoltage / voltage - 1.0);

    temperature = resistance / nominalResistance;

    temperature = log(temperature);

    temperature /= beta;

    temperature +=
        1.0 / (nominalTemperature + 273.15);

    temperature = 1.0 / temperature;

    temperature -= 273.15;

    return temperature;
}

The conversion follows this sequence: 

ADC Reading
     ↓
Voltage
     ↓
Thermistor Resistance
     ↓
Beta Equation
     ↓
Temperature in Kelvin
     ↓
Temperature in Celsius

3. System Initialization

The setup function runs once when the Arduino powers on. It configures the motor-control pin as an output and initializes the 16-column, 2-row LCD. 

void setup()
{
    pinMode(fanPin, OUTPUT);

    lcd.begin(16, 2);
}

4. Temperature Sensing

Every pass through the main loop begins by reading the voltage divider through analog pin A0. 

int rawReading = analogRead(thermistorPin);

float temperature =
    convertToTemperature(rawReading);

The raw ADC value is passed into the conversion function, which returns the current temperature in Celsius.

5. Real-Time LCD Feedback

The first row of the LCD displays the current measured temperature. The value is displayed with one decimal place. 

lcd.setCursor(0, 0);

lcd.print("Temp: ");

lcd.print(temperature, 1);

lcd.print(" C   ");

The second row communicates whether the fan is currently active. 

lcd.setCursor(0, 1);

if (fanOn)
{
    lcd.print("Fan: ON ");
}
else
{
    lcd.print("Fan: OFF");
}

6. Fan Control & Hysteresis

Instead of using one temperature threshold for both turning the fan on and turning it off, the controller uses two thresholds. 

if (temperature >= fanOnThreshold)
{
    fanOn = true;
}
else if (temperature <= fanOffThreshold)
{
    fanOn = false;
}

The fan turns on at 28°C and remains on until the temperature decreases to 27°C. Between those temperatures, the program keeps the previous fan state. 

28°C or higher
      ↓
    FAN ON

27°C – 28°C
      ↓
Keep previous state

27°C or lower
      ↓
    FAN OFF

This hysteresis prevents the motor from rapidly switching on and off if the measured temperature fluctuates around a single threshold.

7. Motor Driver Command

Once the program determines the desired fan state, the Boolean value is sent to Arduino digital pin 9. 

digitalWrite(fanPin, fanOn);

Pin 9 controls the L293D motor driver, which then switches the DC motor. This prevents the Arduino digital pin from directly supplying the motor's operating current.

8. Main Program Loop

Together, the main loop continuously reads the sensor, converts the measurement, updates the display, determines the fan state, and commands the motor driver. 

void loop()
{
    int rawReading = analogRead(thermistorPin);

    float temperature =
        convertToTemperature(rawReading);

    lcd.setCursor(0, 0);
    lcd.print("Temp: ");
    lcd.print(temperature, 1);
    lcd.print(" C   ");

    if (temperature >= fanOnThreshold)
    {
        fanOn = true;
    }
    else if (temperature <= fanOffThreshold)
    {
        fanOn = false;
    }

    lcd.setCursor(0, 1);

    if (fanOn)
    {
        lcd.print("Fan: ON ");
    }
    else
    {
        lcd.print("Fan: OFF");
    }

    digitalWrite(fanPin, fanOn);
}

#include <LiquidCrystal.h>

// ---------- Thermistor ----------

const float referenceVoltage = 5.0;
const int maxADC = 1023;
const float fixedResistance = 5100.0;
const float nominalResistance = 10000.0;
const float nominalTemperature = 25.0;
const float beta = 3950.0;

// ---------- Pins ----------

const int thermistorPin = A0;
const int fanPin = 9;

// ---------- Fan Control ----------

bool fanOn = false;

const float fanOnThreshold = 28.0;
const float fanOffThreshold = 27.0;

// ---------- LCD ----------

LiquidCrystal lcd(12, 11, 5, 4, 3, 2);


// Convert thermistor reading to Celsius

float convertToTemperature(int rawReading)
{
    float voltage;
    float resistance;
    float temperature;

    // ADC reading -> voltage

    voltage =
        (rawReading * referenceVoltage) / maxADC;

    // Voltage -> thermistor resistance

    resistance =
        fixedResistance *
        (referenceVoltage / voltage - 1.0);

    // Thermistor resistance -> temperature

    temperature =
        resistance / nominalResistance;

    temperature = log(temperature);

    temperature /= beta;

    temperature +=
        1.0 /
        (nominalTemperature + 273.15);

    temperature =
        1.0 / temperature;

    temperature -= 273.15;

    return temperature;
}


void setup()
{
    pinMode(fanPin, OUTPUT);

    // 16 columns, 2 rows

    lcd.begin(16, 2);
}


void loop()
{
    // Read thermistor

    int rawReading =
        analogRead(thermistorPin);

    // Convert reading to Celsius

    float temperature =
        convertToTemperature(rawReading);

    // Display temperature

    lcd.setCursor(0, 0);

    lcd.print("Temp: ");

    lcd.print(temperature, 1);

    lcd.print(" C   ");

    // Fan control with hysteresis

    if (temperature >= fanOnThreshold)
    {
        fanOn = true;
    }

    else if (temperature <= fanOffThreshold)
    {
        fanOn = false;
    }

    // Display fan status

    lcd.setCursor(0, 1);

    if (fanOn)
    {
        lcd.print("Fan: ON ");
    }

    else
    {
        lcd.print("Fan: OFF");
    }

    // Actually control the fan

    digitalWrite(fanPin, fanOn);
}
