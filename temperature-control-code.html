Temperature-Controlled Cooling System

The program is divided into several tasks: defining the hardware, reading the thermistor, converting the sensor reading into temperature, controlling the fan using hysteresis, and updating the LCD with real-time system information.

← Back to Project

1. Hardware & System Configuration

The first section defines the electrical characteristics of the thermistor circuit, Arduino pin assignments, fan-control thresholds, and LCD connections. 

#include <LiquidCrystal.h>

const float referenceVoltage = 5.0;
const int maxADC = 1023;
const float fixedResistance = 5100.0;
const float nominalResistance = 10000.0;
const float nominalTemperature = 25.0;
const float beta = 3950.0;

const int thermistorPin = A0;
const int fanPin = 9;

bool fanOn = false;

const float fanOnThreshold = 28.0;
const float fanOffThreshold = 27.0;

LiquidCrystal lcd(12, 11, 5, 4, 3, 2);

Named constants make the program easier to understand and allow hardware values, pin assignments, and temperature thresholds to be changed from one location.

2. Temperature Conversion

The Arduino measures the voltage produced by the thermistor voltage divider. This function converts that ADC measurement into voltage, thermistor resistance, and finally temperature in degrees Celsius. 

float convertToTemperature(int rawReading)
{
    float voltage;
    float resistance;
    float temperature;

    voltage =
        (rawReading * referenceVoltage) / maxADC;

    resistance =
        fixedResistance *
        (referenceVoltage / voltage - 1.0);

    temperature =
        resistance / nominalResistance;

    temperature = log(temperature);

    temperature /= beta;

    temperature +=
        1.0 / (nominalTemperature + 273.15);

    temperature =
        1.0 / temperature;

    temperature -= 273.15;

    return temperature;
}

3. System Initialization

The setup function runs once when the Arduino powers on. It configures the fan-control pin as an output and initializes the 16x2 LCD. 

void setup()
{
    pinMode(fanPin, OUTPUT);

    lcd.begin(16, 2);
}

4. Temperature Sensing

Every pass through the main loop begins by reading the thermistor voltage through analog pin A0. The reading is then passed into the temperature conversion function. 

int rawReading =
    analogRead(thermistorPin);

float temperature =
    convertToTemperature(rawReading);

5. Real-Time LCD Feedback

The first LCD row displays the current measured temperature with one decimal place. 

lcd.setCursor(0, 0);

lcd.print("Temp: ");

lcd.print(temperature, 1);

lcd.print(" C   ");

The second row displays whether the fan is currently on or off. 

lcd.setCursor(0, 1);

if (fanOn)
{
    lcd.print("Fan: ON ");
}
else
{
    lcd.print("Fan: OFF");
}

6. Fan Control & Hysteresis

The controller uses separate activation and deactivation temperatures rather than one threshold. 

if (temperature >= fanOnThreshold)
{
    fanOn = true;
}
else if (temperature <= fanOffThreshold)
{
    fanOn = false;
}

At 28°C or higher, the fan turns on. At 27°C or lower, it turns off. Between 27°C and 28°C, the program maintains the previous fan state.

This hysteresis prevents rapid switching if the measured temperature fluctuates near the activation point.

7. Motor Driver Command

After determining the desired fan state, the program sends that state to Arduino digital pin 9. 

digitalWrite(fanPin, fanOn);

Pin 9 controls the L293D motor driver, allowing the Arduino to command the DC motor without directly supplying the motor's operating current.

8. Main Program Loop

The complete loop continuously reads the sensor, calculates temperature, updates the LCD, determines the fan state, and commands the motor driver. 

void loop()
{
    int rawReading = analogRead(thermistorPin);

    float temperature =
        convertToTemperature(rawReading);

    lcd.setCursor(0, 0);

    lcd.print("Temp: ");
    lcd.print(temperature, 1);
    lcd.print(" C   ");

    if (temperature >= fanOnThreshold)
    {
        fanOn = true;
    }
    else if (temperature <= fanOffThreshold)
    {
        fanOn = false;
    }

    lcd.setCursor(0, 1);

    if (fanOn)
    {
        lcd.print("Fan: ON ");
    }
    else
    {
        lcd.print("Fan: OFF");
    }

    digitalWrite(fanPin, fanOn);
}

#include <LiquidCrystal.h>

// ---------- Thermistor ----------

const float referenceVoltage = 5.0;
const int maxADC = 1023;
const float fixedResistance = 5100.0;
const float nominalResistance = 10000.0;
const float nominalTemperature = 25.0;
const float beta = 3950.0;

// ---------- Pins ----------

const int thermistorPin = A0;
const int fanPin = 9;

// ---------- Fan Control ----------

bool fanOn = false;

const float fanOnThreshold = 28.0;
const float fanOffThreshold = 27.0;

// ---------- LCD ----------

LiquidCrystal lcd(12, 11, 5, 4, 3, 2);


// Convert thermistor reading to Celsius

float convertToTemperature(int rawReading)
{
    float voltage;
    float resistance;
    float temperature;

    // ADC reading -> voltage

    voltage =
        (rawReading * referenceVoltage) / maxADC;

    // Voltage -> thermistor resistance

    resistance =
        fixedResistance *
        (referenceVoltage / voltage - 1.0);

    // Thermistor resistance -> temperature

    temperature =
        resistance / nominalResistance;

    temperature = log(temperature);

    temperature /= beta;

    temperature +=
        1.0 / (nominalTemperature + 273.15);

    temperature =
        1.0 / temperature;

    temperature -= 273.15;

    return temperature;
}


void setup()
{
    pinMode(fanPin, OUTPUT);

    // 16 columns, 2 rows

    lcd.begin(16, 2);
}


void loop()
{
    // Read thermistor

    int rawReading =
        analogRead(thermistorPin);

    // Convert reading to Celsius

    float temperature =
        convertToTemperature(rawReading);

    // Display temperature

    lcd.setCursor(0, 0);

    lcd.print("Temp: ");

    lcd.print(temperature, 1);

    lcd.print(" C   ");

    // Fan control with hysteresis

    if (temperature >= fanOnThreshold)
    {
        fanOn = true;
    }
    else if (temperature <= fanOffThreshold)
    {
        fanOn = false;
    }

    // Display fan status

    lcd.setCursor(0, 1);

    if (fanOn)
    {
        lcd.print("Fan: ON ");
    }
    else
    {
        lcd.print("Fan: OFF");
    }

    // Actually control the fan

    digitalWrite(fanPin, fanOn);
}
