Temperature-Controlled Cooling System

Arduino-based closed-loop temperature monitoring and fan control

I designed and programmed a temperature-controlled cooling system that continuously monitors ambient temperature using an NTC thermistor, displays the temperature and fan state on a 16x2 LCD, and automatically controls a DC fan through an L293D motor driver.

Project Overview

The goal of this project was to create a self-contained system capable of monitoring temperature in real time and automatically activating cooling when the measured temperature became too high.

The fan turns on at 28°C and remains on until the temperature falls to 27°C. This one-degree difference prevents the fan from rapidly switching on and off near a single temperature threshold.

System Architecture

The thermistor forms a voltage divider whose output is measured by the Arduino's analog input. The ADC reading is converted to voltage, thermistor resistance, and finally temperature in degrees Celsius.

Hardware

The system was built using the following components:

Arduino Uno • NTC Thermistor • 5.1 kΩ Resistor • 16x2 LCD • 10 kΩ Potentiometer • L293D Motor Driver • DC Motor • Fan Blade • Breadboard Power Supply • Breadboard • Jumper Wires

Software and Control Logic

The software was written in Arduino C/C++. I separated the temperature conversion into its own function so the main loop could remain focused on reading the sensor, updating the display, and controlling the fan.

The control logic uses hysteresis: 

Temperature ≥ 28°C
        ↓
      Fan ON

27°C < Temperature < 28°C
        ↓
Keep previous fan state

Temperature ≤ 27°C
        ↓
      Fan OFF

The thermistor conversion uses the measured analog voltage to calculate thermistor resistance, then applies the thermistor Beta model to determine temperature in Celsius.

Engineering Challenge: LCD Interference

During testing, the LCD displayed corrupted characters whenever the DC motor began spinning. The temperature sensing and control logic were functioning, but motor startup was disturbing the power supplied to the LCD.

I isolated the problem by testing the Arduino, display, motor driver, and motor connections separately. The issue only appeared when the motor operated from the same power source as the logic electronics.

I resolved the problem by separating the motor power supply from the Arduino logic supply while maintaining a common ground between the two systems. After the change, the fan operated normally while the LCD remained stable.

Result

The completed system continuously displays the measured temperature and fan status. When the temperature reaches the activation threshold, the Arduino commands the L293D motor driver to power the fan. The fan remains active until the temperature falls below the lower threshold.

This project gave me hands-on experience with analog sensing, ADC conversion, embedded programming, motor control, LCD interfacing, circuit debugging, and power-system troubleshooting.

Future Improvements

Future versions could use a compact enclosure, a dedicated PCB, adjustable temperature thresholds, variable fan-speed control using PWM, and improved temperature sensing accuracy.
